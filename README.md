## Overview

This project is being built as a personal finance tool to help users:

- record daily expenses
- categorize spending by type
- review transaction history
- analyze spending patterns over time
- stay within budget goals

The repository is currently in its early stages, with the foundation being established in C++ and planned for future expansion with reporting and persistence features.

## Features

### Planned

- Add new expense entries
- Assign categories such as food, travel, bills, shopping, and entertainment
- View all recorded expenses
- Filter records by date or category
- Generate monthly and weekly summaries
- Set budget limits
- Receive warnings when spending exceeds planned limits

### Future Enhancements

- CSV/text file data storage
- Expense editing and deletion
- Search and sorting support
- Improved reporting dashboard
- User-friendly CLI menu system
- Data export to reports or files

## Tech Stack

- C++
- Standard C++ library
- Command-line interface (CLI)

## Getting Started

### Prerequisites

- C++ compiler such as `g++`
- Terminal or command prompt

### Compile

```bash
g++ basic.cpp -o expense_tracker
```

### Run

```bash
./expense_tracker
```
